# Code of Conduct

## Our standards

Contributors must communicate respectfully, welcome constructive disagreement, and focus criticism on ideas and code rather than people. Harassment, discrimination, threats, deliberate disruption, and publication of another person's private information are not acceptable.

## Scope

This policy applies in repository discussions, pull requests, issues, reviews, and other project spaces, as well as when representing the project publicly.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through the contact options on the repository owner's GitHub profile. Reports will be handled as confidentially as practical. Maintainers may edit or remove content, issue warnings, restrict participation, or ban contributors when necessary to protect the community.

Enforcement decisions should consider context, severity, recurrence, and the safety of affected participants.
